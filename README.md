# 22mcq-pbq

A vanilla HTML/CSS/JS Security+ (SY0-701) exam simulator — Study Mode and Exam Mode. Live at [22mcq-pbq-sim-vercel22.vercel.app](https://22mcq-pbq-sim-vercel22.vercel.app).

## What it does

- Study Mode and timed Exam Mode
- Review screen with full answer breakdown per question
- Static, curated question bank — an earlier live AI-generation feature was replaced with this after reliability issues in testing

## Tech stack

Vanilla HTML/CSS/JS — no framework, no build step.

## Running it

```bash
git clone https://github.com/cyr6x/sy0-701-exam-simulator.git
cd sy0-701-exam-simulator
# open index.html directly in a browser, or serve locally:
python3 -m http.server 8000
```
